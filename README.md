Free English IPTV playlist
Automatically publishes AU, UK and US English-language streams, excluding religious and shopping channels, using IPTV-org public data.
Run Actions > Update IPTV playlist > Run workflow to build immediately. Schedule runs daily.
In Settings > Pages, select GitHub Actions as the publishing source.
Playlist: `https://YOUR-USERNAME.github.io/iptv-playlist/playlist.m3u`
Language is determined from feed metadata; missing-language channels are excluded. Category and name filters are best-effort. Streams may be unavailable or geo-restricted. No credentials should be committed.
